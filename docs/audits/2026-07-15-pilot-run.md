## Bugs the pilot caught (all fixed in VECTOR, on `v2-enforcement`)

1. **`new-project.md` `.gitignore` inline-comment bug** — git has no trailing comments, so
   `mock/  # ...` and `.vector/state.json  # ...` matched nothing; the disposable mock and
   runtime state would leak into git in **every** project. Fixed (comments on their own line;
   added `playground/`).
2. **`bootstrap-github.md` branch-protection command broken** — used `-f` string fields where
   the API needs typed booleans/integers/null → **422 (`"true" is not a boolean`)**. Exactly
   the finicky failure flagged in the confidence assessment. Fixed to a typed JSON body via
   `--input`, plus a documented note that the API returns **403 on a private free-plan repo**
   (needs Pro or a public repo).

## Learnings noted for Phase B (not bugs — carry forward)

- **`vector-revert` must handle merge commits** (`git revert -m 1`) — ship-issue tags the merge
  commit, and reverting it needs the mainline parent flag.
- **A revert that removes tests trips `test-protection`** — `vector-revert` should carry a
  `TEST-CHANGE-JUSTIFICATION` block when it touches tests; and you don't revert the *foundation*
  (reverting T001 correctly failed ci-tests + test-protection).
- **The coverage baseline needs ratcheting up** after the first real coverage; at `0.0` the
  ratchet has no teeth yet (test-protection was the net that actually caught the weakening here).

## Limitations (real deviations — do NOT treat as fixed)

- **Single GitHub identity** (`fedeglan`) — no dedicated machine user (I cannot create GitHub
  accounts). The "machine ≠ human" property that makes branch protection meaningful in
  production was **not** exercised.
- **Repo made public** to enable branch protection on the free plan. A production repo would be
  private on Pro/Team.
- **Only T001 of 5 issues was built** through the full gated loop. T002–T005 follow the
  identical, proven loop; they were not executed (no manufactured green).
- **`webapp` visual gates** (views/mock/baselines/Explorer) remain paper-only.
- **The Tier-2 runner and Act III** are unbuilt (Phase B/E/F) — unchanged, and documented as such.
